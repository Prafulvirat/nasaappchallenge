# NASA App Challenge

This project is a static web experience built around the NASA Space Apps Challenge theme, with a focus on the May 2024 solar storm. It uses HTML, CSS, JavaScript, media assets, and Tailwind CSS via CDN to present the content.

## Project Structure

- `index.html` - main landing page
- `nasa.html` - alternate landing page content
- `nasa2.html` - additional information page
- `nasa.css` - project styling
- `js.js` - front-end interactions
- `*.jpg`, `*.mp4` - media assets used by the site

## Run Locally

Because this is a static site, you can open `index.html` directly in a browser, or serve the folder with a simple local server.

Example with Python:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
